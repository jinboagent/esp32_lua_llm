## Project Overview
ESP32-S3 BLE sniffer dongle for IoT developers. Passive BLE advertisement
scanning → JSON lines over USB CDC → host PC LLM analyzes → generates Lua
scripts → deploys back to device via text-line or hex-chunk upload →
on-device filter/transform hooks. 13 features across 4 stages — **all
implemented, hardware-verified, and every evaluation finding ever logged
against this codebase is closed.**

## Key Decisions & Findings
- **ESP-IDF version drift breaks the build cache**: the build directory had
  been configured against ESP-IDF v5.3.1 (between sessions), while the
  environment default is v5.1 — CMake aborted with a source-mismatch error.
  Deleting `build/` and rebuilding clean fixed it. If this recurs, it is a
  cache problem, not a code problem.
- **B6 guard placement**: component dependency direction (ble already links
  lua for pipeline hooks) forbade a lua→ble check, so the deinit guard went
  into the CLI, which already links both. State guards belong at the layer
  owning both dependencies.
