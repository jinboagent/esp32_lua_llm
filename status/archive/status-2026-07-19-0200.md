## Key Decisions Made

| Decision | Choice | Rationale |
|----------|--------|-----------|
| BLE scope v1 | Advertisements only (passive scan) | Simpler, lower memory. Connections in v2. |
| Lua scope | Filter + transform only | LLM generates scripts, not full pipeline control |
| LLM path | Via host PC over USB | No WiFi needed on device in v1 |
| Output format | JSON lines | LLM-native, universally parseable |
| Lua version | 5.4 | Standard, good ESP32 support |
| Error codes | Module-specific ranges (-100~-999) | Prevents cross-module conflicts |
| Wildcard match | Iterative (not recursive) | Prevents DoS from crafted patterns |
| Filter logic | AND between types, OR within type | Standard filter composition |
| Feature branches | Keep after merge (don't delete) | Allows revert if needed |
| Build workflow | tmux `build_infor` session | Live visibility into all operations |
| Commit format | What/Why/How/Verification sections | Full traceability of decisions |

## Problems Encountered

### 1. No native C compiler on Windows
**Problem:** ESP-IDF only has cross-compilers, can't run host tests
**Solution:** Installed MinGW via MSYS2 pacman (`mingw-w64-x86_64-gcc`)
**Lesson:** Always verify toolchain availability before planning host-side tests

### 2. ESP-IDF version mismatch in build cache
**Problem:** `idf_cmd_init.bat` defaults to v5.1 but build cache had v5.3.1 paths
**Solution:** Delete `build/` directory and rebuild from scratch
**Lesson:** When changing ESP-IDF versions, always clean build

### 3. Hardcoded test data byte counting errors
**Problem:** Multiple attempts to fix BLE AD length bytes — miscounted characters in "LYWSD03MMC" (10 chars, not 9)
**Solution:** Shortened name to "LYWSD03" (7 chars) to fit 31-byte legacy BLE max
**Lesson:** BLE AD length = type + data bytes. Always count total array size.

### 4. Parser -104 on device but not on host
**Problem:** Same data parses on PC but fails on ESP32
**Status:** Still investigating — likely boundary check off-by-one
**Lesson:** Host tests don't catch everything. Always verify on target.
