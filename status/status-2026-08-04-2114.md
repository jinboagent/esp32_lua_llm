## Project Overview
ESP32-S3 BLE sniffer dongle for IoT developers. Passive BLE advertisement
scanning → JSON lines over USB CDC → host PC LLM analyzes → generates Lua
scripts → deploys back to device via text-line or hex-chunk upload →
on-device filter/transform hooks. 13 features across 4 stages — **all four
stages implemented and hardware-verified; firmware at v1.0.0.**

## Key Decisions & Findings This Session
- **Text-line protocol added alongside hex-chunk** (user decision): spec
  protocol implemented exactly; proven hex path kept as extension.
- **USB suspend detection deferred to v2**: USB-Serial/JTAG exposes no
  suspend signal on this hardware (documented in feature doc).
- **PM + console interaction**: during light sleep the USB-Serial/JTAG TX
  FIFO cannot drain and the IDF console drops bytes after ~50 ms; fixed by
  holding a NO_LIGHT_SLEEP PM lock for the whole streaming window.
- **Debugging lesson**: apparent "adv output lost" was mostly a test
  artifact — pyserial `readlines()` blocks/interacts badly with async adv
  streams and BLE dedup suppresses repeats after the initial burst. Raw
  `s.read()` loops immediately after SCAN START are the reliable pattern
  (see test_power_hw.py / test_bridge_hw.py helpers).
- tmux `esp32` session used for build/flash (idle pwsh pane, project dir).
