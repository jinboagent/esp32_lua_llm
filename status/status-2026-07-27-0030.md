# Status Report — 2026-07-27 00:30

## Project Overview
BLE Sniffer Dongle for IoT developers. ESP32-S3 with 8MB PSRAM, NimBLE, USB CDC, LittleFS.
Stages 0-2 complete and verified on hardware. Stage 3 (Lua) is next.

## What's Done
- **Stage 0**: USB CDC console + LittleFS storage ✅
- **Stage 1**: AD parser (NimBLE), JSON encoder (cJSON), filter engine ✅
- **Stage 2**: BLE passive scan, dedup, pipeline (parse→filter→JSON→USB) ✅
- **Bug fixes**: 13 bugs fixed across 2 sessions (B1-B4, M2, M4, M5, L2, L6, JSON escaping, VFS leak, partial write, pipeline crash)
- **BLE hardware verified**: SCAN START produces real JSON from Jabra, Apple, beacons

## Hardware Info
- **Chip**: ESP32-S3 (QFN56) rev v0.2
- **PSRAM**: 8MB (AP_3v3) — Lua engine can use 128KB limit
- **Flash**: 16MB (detected), 4MB (configured)
- **Serial**: COM12 (USB-Serial/JTAG)
- **BLE MAC**: d8:3b:da:9d:24:ce

- Filter connected to pipeline via `pipeline_set_filter()` API (B2 fix)
