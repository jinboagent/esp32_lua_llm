### Code changes (verified: host 86/86 · bridge 32/32 · power 14/14 · ble_lua 45/45)
- **Lua pool rewritten** (`firmware/components/lua/lua_pool.c` +
  `interfaces/lua_pool_if.h`): uint32 offsets/sizes (old uint16 truncated
  past 64 KB of the 128 KB pool — the eval's only correctness bug),
  address-ordered free list with real on-free coalescing, top-block shrink,
  single ledger. 10 new host tests incl. a >64 KB offset regression and a
  free-list offset-0 sentinel regression (both failed on the old allocator
  in spirit; the new one passes).
- **Lock decoupling**: filter engine owns its mutex (`filter_lock/unlock`,
  no-op under HOST_BUILD); pipeline/CLI no longer take the Lua mutex for C
  filters; hook presence cached at SCRIPT RUN/STOP
  (`script_has_on_adv/transform`) — zero Lua lock round-trips per adv.
- `lua_if.h` now pulls `LUA_MEMORY_LIMIT` from `lua_pool_if.h`.
